# PokeMemory

Práctica de JavaScript vanilla: juego Memory con Pokémon, registro de usuario, ranking y logout.

Usa Firebase Realtime Database (con `fetch`) y la PokeAPI.

## Cómo arrancar

```bash
npm install
npm run start
```

Abre http://127.0.0.1:5500

## Comandos

```bash
npm run lint
npm run test:e2e
npm run test:e2e:open
```

## Estructura

- `index.html` — marcaje
- `css/` — estilos
- `js/` — lógica (módulos con import/export)
